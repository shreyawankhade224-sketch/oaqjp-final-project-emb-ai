HOW TO RUN IN THE ACTUAL IBM SKILLS NETWORK CLOUD IDE ENVIRONMENT
(/home/project/final_project)
================================================================================
1. Open the Cloud IDE terminal in your Coursera course.
2. Navigate to your project directory or clone your repository:
   cd /home/project
   git clone https://github.com/shreyawankhade224-sketch/oaqjp-final-project-emb-ai.git final_project
   cd final_project

3. Run unit tests (uses live Watson NLP internal endpoint):
   python3 -m unittest test_emotion_detection.py

4. Run Pylint to verify 10.00/10 rating:
   pylint server.py
   pylint EmotionDetection/emotion_detection.py

5. Start the web application:
   python3 server.py

6. Open the Web Browser preview on port 5000:
   - Click the "Launch Application" icon or navigate to the port 5000 web preview.
   - Enter: "I think I am having fun" and click "Run Sentiment Analysis".
   - Clear the input box and click "Run Sentiment Analysis" to view "Invalid text! Please try again!".
